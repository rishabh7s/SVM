Product Positioning Statement

&nbsp;

Kivi is a text tool which turns the scattered information into a clear action plan. Instead of trying to do the work for the user, it helps the user organize multi-step tasks, which might not be visible, so that the user does not waste time repeating. It connects different applications, brings up past information exactly when the user needs it, and keeps the daily work flowing smoothly. Kivi also protects users’s privacy by only recording what the user explicitly chooses to save.

&nbsp;

&nbsp;

Product Vision Document&nbsp;

&nbsp;

Consider a person A, an R\&D engineer who is juggling multiple parallel research. He hits a bottleneck on an experiment and schedules a quick meeting with Colleague B to get it resolved. In a normal scenario, A would walk into that meeting, ask his one specific question would get the answer, and then leave.

&nbsp;

But the reality is that the work of A is scattered. In an entirely different unfinished task of A he also required B’s expertise. Because our human memory is not perfect because of which, A completely overlooks it. He walks out of the meeting leaving crucial work undone.  
This shows that many times a user's work is scattered across many different apps and there is a need for something to hold all that together. Something which would hold all those pieces together, but would also keep sensitive information hidden. In the above scenario A couldn’t have directly shared his company R\&D with an assistant which takes the whole control of the PC.&nbsp;

&nbsp;

So, Kivi won’t try to complete tasks for the user, rather it would track their unfinished work and show how different projects connect. Kivi would also help in organizing the user's tasks and helping them easily navigate what they already know. When the user would plan a task or meeting, Kivi would look at their unfinished work and suggest the best order to tackle it, like reminding them to ask a question before attending the meeting. It would also save the user’s time by remembering past solutions, suggesting fix for a problem so they do not have to do research for it all over again.Also, Kivi would keep track of the user's thoughts over time, making sure no important things slip out of the mind of the user, as user switches between different tasks and apps.&nbsp;

Also, it won’t save everything, it would have only the important information that helps the user actually get things done. It would keep track of proven facts, fixes, deadlines, preferences and upcoming tasks including the specific order in which things need to happen. It would also remember exact solutions to past problems so the user can easily use them again. Kivi would ignore casual chat, temporary ideas, and sensitive information like passwords.&nbsp;

And, if Kivi does not have the required information saved in its history, it would simply say it does not know rather than hallucinating.

Eventually its predictable and transparent nature would help it gain trust of people, as it shows where its information comes from. It would not store information from the background unless explicitly asked for, only saving exactly what the user intentionally speaks or highlights. Whenever Kivi brings up a past solution or suggests a task order, it would show exactly when and where that information was originally saved.. By showing its work and admitting when it does not have a record of something, Kivi would be a tool that the user can depend upon every day.&nbsp;
